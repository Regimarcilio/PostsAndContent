# Visual palette

Paleta editorial aproximada da referência visual fornecida pelo usuário:

| Papel | Cor |
|---|---|
| Fundo azul-petróleo | `#073B46` |
| Painel | `#0B4B54` |
| Texto principal | `#F8FBF7` |
| Texto auxiliar | `#BED4D2` |
| Ciano/mint | `#76E0D7` |
| Laranja | `#FF9347` |
| Amarelo | `#F2C84B` |
| Roxo | `#51496F` |
| Borda escura | `#2D6A70` |

Uso:

- ciano/mint para estrutura, conexões e estados de leitura;
- laranja para problema, transição e destaque de atenção;
- amarelo para direção e ação;
- roxo para estados secundários;
- branco e cinza-azulado para hierarquia tipográfica.

As cores foram aproximadas visualmente a partir da imagem de referência; não representam uma extração exata de pixels.
